# Data Analytics Projects

## Overview

This repository contains four data analytics projects completed using Python, Pandas, data visualization libraries, and SQL Server. These projects demonstrate different stages of the data analytics process, from data cleaning and exploratory data analysis to SQL-based analysis and visualization.

## Projects

### Project 1: Data Cleaning

* Load and inspect the dataset.
* Handle missing values and duplicate records.
* Check data types and data consistency.
* Perform data quality checks.
* Export the cleaned dataset for further analysis.

### Project 2: Exploratory Data Analysis (EDA)

* Explore the dataset using descriptive statistics.
* Analyze numerical and categorical columns.
* Identify outliers and patterns.
* Examine relationships between variables.
* Generate insights from the data.

### Project 3: SQL Data Analysis

* Import the dataset into SQL Server.
* Query and analyze data using SQL.
* Apply filtering, sorting, grouping, and aggregate functions.
* Extract meaningful information from the database.

### Project 4: Data Visualization

* Create charts to explore and communicate findings.
* Visualize distributions, comparisons, and trends.
* Present data-driven insights through graphical analysis.

## Tools and Technologies

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* SQL Server
* SQL Server Management Studio (SSMS)

## Dataset

The projects use an order dataset containing information such as order dates, customers, products, quantities, unit prices, payment methods, order statuses, referral sources, and total prices.

## How to Run the Projects

1. Clone or download this repository.
2. Install Python and Jupyter Notebook.
3. Install the required Python libraries.
4. Open the relevant `.ipynb` file in Jupyter Notebook or VS Code.
5. Ensure the required dataset is available in the expected location.
6. Run the notebook cells in order.

> **Note:** Project 3 may require SQL Server and a configured database connection. Update the connection settings to match your local environment if necessary.

## Purpose

The purpose of these projects is to practice data cleaning, exploratory data analysis, SQL querying, and data visualization while developing practical data analytics skills.
